# for-declaration-grammar-basic

tsc's `checkGrammarForInOrForOfStatement` on the loop's declaration — one
declaration only (TS1091/TS1188), no initializer (TS1189/TS1190), no type
annotation (TS2404/TS2483) — and `checkGrammarTypeOperatorNode`'s rules that
`unique symbol` needs a plain name (TS1333) in a variable statement (TS1334).
