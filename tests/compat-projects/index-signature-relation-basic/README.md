# index-signature-relation-basic

`indexSignaturesRelatedTo`: a target index signature is satisfied by the
source's applicable one, or by every source member it would cover, and an
`any`-valued signature asks for nothing once the target has a string
index. A source's own index signature does not supply a *required* target
property. surge checked neither direction. Two instantiations of
`Record` relate by the variance tsc measures, with `K` contravariant.
