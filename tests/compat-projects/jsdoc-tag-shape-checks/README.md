# jsdoc-tag-shape-checks

JSDoc tag shape rules in a checked JavaScript file: a `@param` naming no
parameter (TS8024), a qualified `@param` name without its root (TS8032), a
`@type` signature with fewer parameters than the function (TS8030), two
`@type` tags in a `@typedef` (TS8033), `@template` after `@typedef` (TS8039),
and a braced `@template` name (TS1069).
