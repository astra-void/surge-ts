# primitive-apparent-type-basic

Every primitive relates to an object type through its apparent type. `bigint`
and `symbol` had none, so `{ toString(): string }` rejected them and the
`object` keyword accepted them. A `number`, `boolean` or `bigint` against a
target requiring a member no such value has is a definite mismatch, reported
even where the target carries an overload fold surge could not fully model.
A method member prints in method form and the `object` keyword as `object`.
