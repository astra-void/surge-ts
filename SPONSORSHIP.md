# Sponsoring surge-ts

`surge-ts` is developed independently. Sponsorship pays for the time spent on
`tsc` compatibility work, real-project validation, and performance and memory
work.

## How to sponsor

There is no public sponsorship platform set up yet. If you or your company
would like to sponsor the project, send an email to
**dev@astra-void.xyz** with:

- who you are (individual or company name)
- the kind of support you have in mind (one-time or recurring)
- anything you would like prioritized, such as a project or TypeScript feature
  you depend on

You will get a reply to work out the details.

If enough sponsorship requests come in, a GitHub Sponsors profile will be set
up so that support can be given directly through GitHub.

## What sponsorship covers

- Continued work on `tsc`-compatible diagnostics, measured against the upstream
  compiler as an oracle
- Validation on real-world TypeScript projects
- Checking performance and bounded memory use

Sponsorship does not buy a guarantee of compatibility with a particular
project. What is supported right now is recorded in
[CURRENT_STATUS.md](CURRENT_STATUS.md).

## Other ways to help

- Report a divergence from `tsc` with a minimal reproduction
- Point us at an open-source project where `surge-ts` and `tsc` disagree
